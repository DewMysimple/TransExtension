# 项目概览

## 项目名称

TransExtension

## 项目目标

统一开发和管理针对特定网站的简体中文界面翻译扩展。每个插件独立安装、测试和打包，根项目统一维护共享工程规则、工程记忆与 Git 历史。

## 当前阶段

已有 Figma 与 GitHub 两个可运行插件；根级工程治理、集中式工程记忆和统一 Git 仓库已建立。
