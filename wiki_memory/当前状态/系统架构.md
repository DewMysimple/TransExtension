# 系统架构

## 架构概览

TransExtension 是一个根级治理仓库，包含两个运行时互不依赖的浏览器扩展。根层只负责共享规则、工程记忆和版本控制，不把两个插件合并为同一运行包。

每个插件均采用 Chrome/Edge Manifest V3：打包的离线词库和人工覆盖进入翻译核心，内容脚本观察单页应用的动态 DOM，在保护规则允许时替换固定界面文本；background 与 popup 管理设置、状态和本地漏译审计。

## 模块关系

| 模块 | 职责 | 运行时依赖 | 入口 |
| --- | --- | --- | --- |
| 根治理层 | 共享规则、记忆、Git 和跨插件导航 | 不参与扩展运行 | `README.md`、`AGENTS.md` |
| Figma 扩展 | 翻译 Figma 固定 UI，保护设计及用户内容 | 仅自身打包文件 | `figma-zh-ui/manifest.json` |
| GitHub 扩展 | 翻译 GitHub 固定 UI，保护代码及用户内容 | 仅自身打包文件 | `github-zh-ui/manifest.json` |
| 工程记忆 | 当前事实、决策、稳定知识与历史日志 | 根级 Markdown 与标准库 Python | `当前状态/`、`日志/MOC_工作日志.md` |

插件细节见 [[知识/模块/figma-zh-ui|figma-zh-ui 模块]] 与 [[知识/模块/github-zh-ui|github-zh-ui 模块]]。

## 插件运行流

1. Manifest 按 dictionary → official overrides → core → content 的顺序加载内容脚本。
2. 内容脚本识别路由、元素语义和保护区域。
3. 可确认的固定 UI 按人工覆盖和生成词库的优先级查找译文。
4. 替换时保留原文标记，以支持悬停查看和关闭后的恢复。
5. DOM 观察器处理异步菜单与 SPA/Turbo 导航。
6. 只对安全白名单内的未知固定控件生成本地漏译候选。

## 开发与交付流

两个插件分别拥有 `package.json`、测试、验证和打包脚本。跨插件任务按影响范围分别验证，不共享 `node_modules` 或发布产物。统一流程见 [[知识/流程/开发验证与发布|开发验证与发布]]。
