# Figma 简体中文界面

一个面向 Chrome 和 Edge 的离线 Manifest V3 扩展。它翻译 `www.figma.com` 的固定导航、按钮、菜单、工具提示、文件浏览器、设置和编辑器界面，同时保护文件名、项目名、团队名、图层名、画布文字、评论和用户输入。

## 功能

- 词库随扩展打包；运行时不调用翻译 API，也不下载脚本或远程词库。
- 优先覆盖 Figma 文件浏览器，包括“最近查看”“与你共享”、团队文件、草稿、项目、回收站和设置。
- 兼容 Figma Design、FigJam、Slides、Community、账户设置和团队管理中的固定控件。
- 支持 Figma 单页应用的异步导航、菜单、弹窗和动态工具提示。
- 默认显示简体中文；在译文上悬停约 0.4 秒可查看原始英文。
- 关闭扩展后，仍在页面中的译文会恢复为原始英文。
- 未收录的候选固定控件可进入本地漏译报告；不会保存完整 URL、文件名、图层、评论或输入内容。

## 安装

先将 `dist/figma-zh-ui.zip` 解压到任意文件夹，再在浏览器中选择这个包含 `manifest.json` 的解压目录。后续版本会直接覆盖同名 ZIP，不会在文件名中追加版本号。

### Chrome

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择你解压得到的 `figma-zh-ui` 文件夹。
5. 刷新已经打开的 Figma 页面。

### Edge

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择你解压得到的 `figma-zh-ui` 文件夹并刷新 Figma。

点击浏览器工具栏中的扩展按钮，可以启停中文化、悬停英文和本地漏译审计，也可以重新扫描、导出或清空漏译报告。

## 隐私与保护边界

扩展只申请：

- `https://www.figma.com/*`：在 Figma 网页运行界面翻译；
- `storage`：保存三个开关和本地漏译报告；
- `activeTab`：打开扩展弹窗时读取当前标签页的翻译统计。

扩展不申请 Cookie、历史记录、下载、网络拦截或脚本注入权限。运行代码没有外部网络请求。画布、设计文字、文件卡片链接、可拖拽项目、图层树、变量名、评论、文本框和可编辑区域进入强制保护名单。漏译审计只接受菜单、弹窗中的按钮及带明确无障碍标签的固定控件。由于 Figma 的类名会持续变化，首版采用保守策略：不能确认是界面文字时宁可保留英文，也不修改设计内容。

## 词库来源与更新

简体中文词库基于 GPL-3.0 项目 [`Figma-Cool/figmaCN`](https://github.com/Figma-Cool/figmaCN)，并固定到构建时的最新提交；常用术语和页面结构使用 Figma 官方帮助中心核对。确切提交和生成时间见 [`generated/sources.json`](generated/sources.json)。

需要 Node.js 22 或更高版本：

```powershell
npm install
npm run update:sources
npm test
npm run verify
npm run package
```

`update:sources` 获取上游默认分支最新提交，再按该 SHA 下载并生成离线词库。`package` 要求来源元数据在最近 24 小时内生成。交付文件固定为 `dist/figma-zh-ui.zip`，每次打包直接覆盖。

## 验收建议

安装后依次检查：你提供的团队“最近查看”页面、与你共享、草稿、任一项目、账户设置，以及一个 Figma Design 文件。重点确认文件名、团队名、图层名、画布文字和评论完全未改变。弹出一个未知英文菜单项时，它应在约两秒内进入漏译审计；如发现 Figma 更新带来的漏译，可导出报告补充人工覆盖词条。
