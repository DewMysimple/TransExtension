# Figma 简体中文界面

一个面向 Chrome 和 Edge 的离线 Manifest V3 扩展。它翻译 `www.figma.com` 的固定导航、按钮、菜单、工具提示、文件浏览器、设置和编辑器界面，同时保护文件名、项目名、团队名、图层名、画布文字、评论和用户输入。

## 功能

- 词库随扩展打包；运行时不调用翻译 API，也不下载脚本或远程词库。
- 优先覆盖 Figma 文件浏览器，包括“最近查看”“与你共享”、团队文件、草稿、项目/文件夹、回收站和设置。
- 兼容 Figma Design、FigJam、Slides、Community、账户设置和团队管理中的固定控件。
- 支持 Figma 单页应用的异步导航、菜单、弹窗和动态工具提示。
- 默认显示简体中文；在译文上悬停约 0.4 秒可查看原始英文。
- 关闭扩展后，仍在页面中的译文会恢复为原始英文。
- 未收录的候选固定控件可进入本地漏译报告；不会保存完整 URL、文件名、图层、评论或输入内容。

已收录词条支持内部换行和不换行空格；固定控件的 `title` 等提示属性也参与翻译。普通面板的 `translate="no"` 不再阻断可确认的固定按钮、菜单、工具提示和 `i18n-text`，但用户内容保护仍优先。拆分文案仅对纯文本或无属性 `span` 组成的已知 `i18n-text` 整句处理；带动态名称、强调格式或交互子元素的内容继续保守处理。覆盖回归见 `tests/fixtures/figma-ui-coverage.json`，其中记录页面类别和官方参考来源。

## 安装

先将 `dist/figma-zh-ui.zip` 解压到任意文件夹，再在浏览器中选择这个包含 `manifest.json` 的解压目录。后续版本会直接覆盖同名 ZIP，不会在文件名中追加版本号。

### Chrome

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择你解压得到的 `figma-zh-ui` 文件夹。
5. 刷新已经打开的 Figma 页面。

### Edge

1. 打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择你解压得到的 `figma-zh-ui` 文件夹并刷新 Figma。

点击浏览器工具栏中的扩展按钮，可以启停中文化、悬停英文和本地漏译审计，也可以重新扫描、导出或清空漏译报告。

开发时也可直接加载本插件源码目录（其中包含 `manifest.json` 和已提交的 `generated/`）；修改后在扩展管理页点击重新加载，再刷新 Figma。源码修改不会自动更新已有 ZIP，验收时应确认加载的是本次修改后的目录。

## 隐私与保护边界

扩展只申请：

- `https://www.figma.com/*`：在 Figma 网页运行界面翻译；
- `storage`：保存三个开关和本地漏译报告；
- `activeTab`：打开扩展弹窗时读取当前标签页的翻译统计。

扩展不申请 Cookie、历史记录、下载、网络拦截或脚本注入权限。运行代码没有外部网络请求。画布、设计文字、文件卡片链接、可拖拽项目、项目/文件夹/工作区名称、图层树、变量名、评论、文本框和可编辑区域进入强制保护名单。已知文件浏览器外壳的拖拽标记不影响其固定导航，内部拖拽卡片继续受保护。漏译审计只接受菜单、弹窗中的按钮及带明确无障碍标签的固定控件；延迟发送前再次检查来源仍存在、文字未变且仍属于安全控件。关闭扩展或审计会取消待发送候选。由于 Figma 的类名会持续变化，不能确认是界面文字时宁可保留英文，也不修改设计内容。

## 词库来源与更新

简体中文词库基于 GPL-3.0 项目 [`Figma-Cool/figmaCN`](https://github.com/Figma-Cool/figmaCN)，并固定到构建时的最新提交；常用术语和页面结构使用 Figma 官方帮助中心核对。确切提交和生成时间见 [`generated/sources.json`](generated/sources.json)。

需要 Node.js 22 或更高版本：

```powershell
npm ci
npm run update:sources
npm test
npm run verify
npm run package
```

`update:sources` 获取上游默认分支最新提交，再按该 SHA 下载并生成离线词库。`package` 要求来源元数据在最近 24 小时内生成。交付文件固定为 `dist/figma-zh-ui.zip`，每次打包直接覆盖。

普通源码修复使用 `npm ci`、`npm test` 和 `npm run verify:offline`，无需刷新上游。`verify:offline` 保留权限、离线约束、加载顺序、版本、来源结构和交付文件检查，仅跳过来源年龄；发布用的 `npm run verify` 仍要求 24 小时时效。跨插件维护可在仓库根目录运行 `npm run check`，定位漏译的方法见 [维护指南](../docs/maintenance.md)。

修改扩展加载、后台、设置、消息或导出时，在根目录安装开发依赖后运行 `npx playwright install --no-shell chromium` 和 `npm run test:browser`。测试使用原始清单和真实扩展 API，页面为合成 fixture，不能替代下方真实站点验收。

## 验收建议

在 Chrome/Edge 加载本次修改后的目录，按下表记录实际可访问的页面；无权限或未执行的页面单独标记为未验收。

| 场景 | 固定界面检查 | 同页保护对照 |
| --- | --- | --- |
| 文件浏览器：最近查看、与你共享、草稿、项目、回收站 | 导航、筛选、排序、创建菜单、卡片操作菜单及弹窗 | 文件名、项目名、团队名、可拖拽卡片 |
| Figma Design | 顶部菜单、工具栏、左右侧栏固定标签、属性工具提示、分享/导出弹窗 | 图层名、画布文本、变量名、组件名、评论、输入值 |
| FigJam | 工具栏、菜单、分享与导出操作 | 便签、白板文本、对象名称与评论 |
| Slides | 演示工具栏、菜单、分享/演示弹窗 | 幻灯片标题、正文、演讲者备注与评论 |
| Community | 固定导航、筛选、按钮及菜单 | 社区资源标题、作者、资源说明与评论 |
| 账户设置与团队管理 | 设置分组、固定表单标签、角色菜单、保存/取消/确认按钮 | 姓名、团队名称、邮箱、成员名称、输入框 |

每组至少打开一次异步菜单或工具提示，通过站内链接导航后再检查。已收录且能确认是固定 UI 的文本及 `title`、`aria-label` 应翻译；保护对照应逐项保持原样。在站点更新同一控件文案后关闭扩展，核对文本和属性恢复最新原文；重新开启再检查一次。对于悬停原文、审计开关和清空/导出，各执行一次操作。

安全白名单内的未知英文菜单项应进入本地漏译审计，导出内容不得含设计文字、名称或完整 URL。漏译可能来自词条缺失、控件上下文、分拆文本或动态更新，先按维护指南归因再补测试。不能确认是固定 UI 的内容会保留原文；自动测试和词库条数不代表所有真实页面已完成翻译。
